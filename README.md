## 凌晨一点十七分，你怎么还没睡？

被窝里亮着一小块蓝光。网页还在连接，小说还剩一页。耳机线绕在手心，短信写好又删掉，论坛里有人给你回了一个“晚安”。

旧日未关机想找回这种上网的感觉：选一个年份，翻翻那年的新闻，去旧站看看，在一部能点按的复古手机里读故事、听配乐、玩一局贪吃蛇，再把带手机外壳的画面存下来。

当前为 **v0.4 口袋时光版**。仓库为私有，网站对外提供体验；宣传使用网站入口，不使用私有仓库链接。项目采用静态部署，手机与电脑均可访问。

## 三种入口，各有自己的旧时光

- **口袋时光**：18 种设备风格，6600、N73、5230 可拿起 3D 开机。游戏按战棋、冒险、休闲分类，可搜索、收藏和继续上次玩的游戏；小说支持书名/作者搜索、续读。
- **重连旧网**：复古电脑桌面与网址收藏夹，浏览旧站、年度新闻和论坛，不套手机外壳。
- **旧巷来客**：走进旧巷手机店，翻找柜台和抽屉，探索三部独立手机中的短信、QQ、相册与浏览记录。普通游玩不会出现剧情短信。

机型、年代、网页和阅读位置按分区保存，可在顶部随时切换。当前游戏厅包含 15 款开源 Java 重制和《水晶》GBC 兼容版；《古代帝国 II》仍因移动端绘制异常暂停启动，已有存档不删除。存档盒包含分区状态、收藏与阅读记录，**不包含模拟器内部的 Java/GBC 进度**。

## 放学别关机：一只等你下课的小伙伴

手机桌面和游戏厅可进入原创养成玩法：三站回合探险、弹珠攻击、书包防守、汽水补给、河边时机钓鱼、升级及12件纪念品收藏。用游戏里的零花钱买饭团恢复体力，来信留在普通手机短信中。成长与收藏保存在本机并可随存档盒备份；进行中的战斗刷新后需重开。

手机访问“重连旧网”时显示 UC / Opera Mini 风格的 WAP 页面，可切换画风、浏览新闻详情与网址目录；电脑访问仍显示电脑桌面。两种画风均为本站重制。

## 留住手感，也说清来源

新闻为有来源的后期历史资料整理，不冒充当年的即时报道。旧站目录是候选入口，不保证每个年份都有可用快照；存档站可能限制嵌入，历史登录、点播和软件下载服务也可能已经失效。

社区和短信是本机模拟：不连接旧账号，不发送真实短信，也不收费。体验帖、图文故事和广告均为新创作；配图标注 AI 辅助生成，非历史照片。回帖、书签、阅读进度与小游戏状态只保存在本机。

Java ME 属于兼容性实验，已经验证原创 Canvas 游戏与工具，不能保证任意旧软件可用。高级控件、3D、音频与旧联网服务仍有限制。经典存档区明确标注第三方来源、版本与校验值，游戏数据保留原权利，不属于开源重制游戏。组件许可证与对应源码可从实验室下载，私有宿主代码与第三方运行组件分别管理。

## 在自己电脑运行

需要 Python 3，无需安装前端依赖：

```sh
python3 -m http.server 4173 --directory dist
```

打开 `http://localhost:4173/`。静态服务器必须发布整个 `dist/`，小说、年表与 Java 运行组件在打开对应频道时加载。

开发检查：

```sh
node scripts/check.mjs
```

需要 Node.js 与 Python 3。Java 示例已有编译产物；重新编译可参考 `scripts/build-java-demos.py`。Java 运行组件保留自己的来源和构建材料。

### 两款经典游戏怎么玩

首页 → 游戏 → 古代帝国 II / 宠物小精灵·水晶，即可在旧手机外壳中运行；可在手机型号菜单换机型。

- **古代帝国 II 1.0.2（英文历史版）**：方向键移动，5 确认，左右软键菜单 / 返回。Game → Skirmish 可直接进入遭遇战，Save Game 保存，Load Game 继续。已实测选兵移动、保存、刷新及恢复 Icy Paths 战局。
- **水晶英文版（GBC 兼容模式）**：5=A，0=B，#=Start，左软键=Select。1 即时存档，3 读档，9 切换 3 倍速，* 暂停。已实测领取火球鼠、野外遭遇战、攻击及重启后恢复战斗。归档 MeBoy 包中的原卡带由 GameBoy-Online 兼容内核运行，不冒充 Java 原生移植。

存档仅属于当前浏览器和当前访问地址；清理网站数据会丢失存档。测试覆盖上述流程，未完成全战役 / 全图鉴通关。历史包来源与 SHA-256 见 `dist/javame/classic-games/catalog.json`，GBC 内核许可保留在 `dist/javame/gb/LICENSE-NOTICE.txt`。

手机端兼容性复查（2026-10-19）：《古代帝国 II》在 390×844 视口的手机外壳内出现右侧黑块、条纹及菜单底图重叠，暂时撤下游戏厅、手机选择器及独立运行器入口，默认改为口袋战棋。原游戏包与浏览器存档保留，修复显示并重新验收后再恢复。其余15款开源游戏已逐款进入游戏并检查基本按键；这不等于完整通关验收。
