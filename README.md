## 凌晨一点十七分，你怎么还没睡？

被窝里亮着一小块蓝光。网页还在连接，小说还剩一页。耳机线绕在手心，短信写好又删掉，论坛里有人给你回了一个“晚安”。

考古浏览器想找回这种上网的感觉：选一个年份，翻翻那年的新闻，去旧站看看，在一部能点按的复古手机里读故事、听配乐、玩一局贪吃蛇，再把带手机外壳的画面存下来。

当前为 **v0.4 口袋时光版**。仓库为私有，网站对外提供体验；宣传使用网站入口，不使用私有仓库链接。项目采用静态部署，手机与电脑均可访问。

## 留住手感，也说清来源

新闻为有来源的后期历史资料整理，不冒充当年的即时报道。旧站目录是候选入口，不保证每个年份都有可用快照；存档站可能限制嵌入，历史登录、点播和软件下载服务也可能已经失效。

社区和短信是本机模拟：不连接旧账号，不发送真实短信，也不收费。体验帖、图文故事和广告均为新创作；配图标注 AI 辅助生成，非历史照片。回帖、书签、阅读进度与小游戏状态只保存在本机。

Java ME 属于兼容性实验，已经验证原创 Canvas 游戏与工具，不能保证任意旧软件可用。高级控件、3D、音频与旧联网服务仍有限制。本站不提供商业 JAR 游戏合集。组件许可证与对应源码可从实验室下载，私有宿主代码与第三方运行组件分别管理。

## 在自己电脑运行

需要 Python 3，无需安装前端依赖：

```sh
python3 -m http.server 4173 --directory dist
```

打开 `http://localhost:4173/`。静态服务器必须发布整个 `dist/`，小说、年表与 Java 运行组件在打开对应频道时加载。

开发检查：

```sh
node scripts/check.mjs
```

需要 Node.js 与 Python 3。Java 示例已有编译产物；重新编译可参考 `scripts/build-java-demos.py`。Java 运行组件保留自己的来源和构建材料。

## 服务器与发布
