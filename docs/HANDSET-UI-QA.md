# 手机界面与隐藏案件验收（2026-10-20）

## 实现
手机外仅设备启动器与年代操作；手机内浏览器统一命名，UC/Opera/WAP三皮肤保持搜索与当前内容。手机窄屏折叠探索目录，保留设备外壳与放大退出。四向按键采用明确九宫位置，中央确认独立，左右功能/绿红键不挤压导航。

3310/1100采用Navi、C、上下滚动键组，不再强加彩屏手机四向摇杆。3310参考Nokia原厂用户手册的Navi/Scroll/C章节（镜像存档）：https://www.manuallib.com/download/NOKIA-3310-USER-GUIDE.PDF 。6600参考Nokia原厂手册的五向Joystick与Selection keys：https://www.telefonguru.hu/manuals/nokia_6600_en.pdf 。网页仍是风格重制，不能称所有机型原厂系统或尺寸完全一致。

## 测试记录
- 原创案件从短信开始，经手机包、QQ离线留言、浏览器实际搜索、论坛四处收集：4/4证据，正确推理完成。
- 只有1/4证据时即使答案正确也不能结案；四证据齐后错误日期被拒，正确日期与归还对象结案。
- 逻辑测试覆盖完成状态重载、损坏存档与非法证据过滤；全仓检查脚本包含案件测试。
- 手机390×844界面人工查看：无外层重复UC地址栏/菜单，应用目录默认折叠，Opera皮肤可用。其他尺寸与按键检查见后续实际记录。
- 实测320/360/390/430宽：页面scrollWidth分别等于视口宽，数字键高度≥44px，外层地址栏、UC标题和移动浏览器菜单均不可见。
- 390宽彩屏导航上/左/中/右/下五键均44×44且各占独立格；实际右移后中央确认启动“应用下载”。
- 案件完成后刷新再进入短信，4/4证据及已结案保持。UC→Opera→WAP切换，刷新后WAP保留。
- 放大模式切到844×390横屏发现退出入口消失，已修复横屏媒体条件并复测：退出可见可点，页面宽844无横向溢出。
- 63项JavaScript测试、4项Python检查通过。本记录是浏览器模拟尺寸验收，不等于所有实体手机系统兼容认证。
