# 口袋时光世界 / v0.4

本版把怀旧入口扩展为可操作的网页体验。项目仓库为私有；外部宣传只使用网站访问地址，不使用仓库链接。

## 已实现

- 五种非官方手机外观：黑白直板、早期彩屏、金属翻盖、音乐手机、初代触屏；六种网页配色与可选屏幕纹理。
- 手机内新闻、原创及公版小说、配乐、开放影片、短信、广告、图文故事与壁纸。图片故事可用方向键或数字 4/6 翻页，2/8 滚动。
- 12 款原创年代广告，按年份筛选。杂志封底、彩铃/壁纸代码与短信回复均为本机模拟，不连接真实收费号码。
- 原创 JavaScript 贪吃蛇、扫雷、方块游戏，以及现有家园菜园、精武堂。
- 真正的 Java ME 字节码运行：Mozilla PluotSorbet VM + 本站编写的 Snake、计算器、RMS 记事本；支持本机 JAR 导入。运行组件首次进入才加载。
- 深夜图文馆：三篇原创图文故事，标题、主题与正文检索、标签、熄灯阅读、手机内四页夜读、图片保存。
- 社区客厅：按年份开放天涯、猫扑、贴吧、QQ 家园、空间、豆瓣、校内、朋友网风格页面；版面、楼层、本机回帖、个人小卡片与历史站点入口。
- PNG 截图在本机生成。可导出完整物理手机外壳；视频和跨域存档可能显示占位。

## 来源和边界

历史新闻与存档延续原有来源标注。社区不是历史服务器，体验帖和楼主均为创作角色。回帖只保存在本浏览器 localStorage，不向其他用户展示。不会索取历史站点密码。

公版经典从维基文库固定版本整理：《西游记》《三国演义》《红楼梦》各前五回，不是整本。章节 JSON 内保留来源、修订历史与许可说明；原作与现代编校贡献需按各自标识使用。

深夜图文配图由内置 image generation 工具辅助生成，主题为 2004 年雨夜被窝手机、2005 年晚自习校园、2003 年县城车站，均明确标注非历史照片。原始提示词见 `data/memory-image-prompts.json`。

四首配乐：三段本站原创合成旋律；《致爱丽丝》为贝多芬公版旋律的本站合成演奏，不使用商业歌曲录音或采样。开放动画保留 Blender Foundation 等署名及 CC BY 链接，来自 Internet Archive，按发行年份显示。

Java ME 仍属实验兼容层。低层 Canvas 示例已经运行验证；部分高级 MIDP 控件、音频、3D、网络与旧服务未实现。导入 JAR 不上传，默认不提供远程 socket、相机、通讯录、定位和真实短信能力。不要把它宣传为全部 Java 游戏通用模拟器。

## 第三方组件

- html2canvas 1.4.1：MIT，`dist/vendor/html2canvas-LICENSE.txt`。
- PluotSorbet：VM 为 Apache-2.0，Java 类库主要 GPL-2.0-only；另有原始第三方许可，见运行组件源码包及 `dist/javame/RUNTIME-NOTICE.txt`。该组件的对应源码公开随站下载，与私有宿主项目分离。
- Java 原创示例按 GPL-2.0 发布，对应 Java 源码及许可随示例源码压缩包提供。

## 验证

运行 `node scripts/check.mjs`。还需在真实浏览器检查手机外壳、导出 PNG、触屏游戏、JAR 导入、Java 计算及记事本保存。静态单元测试不能代替 Canvas/JVM 运行验证。
