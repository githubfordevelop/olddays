# Pocket playground content and capabilities

The three new puzzle games (Lights Out rules, memory pairs, sliding numbers), contact dialogue, fake carrier billing and device toys are original local code. Cheats only affect these original games; no commercial game cracking or DRM bypass is included. The existing 15 MIT Java games remain in the compatible handset shelf. iPhone, modern touchscreen devices and the new media players reject Java launches.

Device catalogue years for generic MP3/MP4/MP5 and the rotating phone denote recreated period styles, not a claim of one exact manufacturer's release. The MP5 is explicitly a networking concept variant. The PSP styled shell uses the site's own games, not a PSP emulator or commercial ROM library. Offline MP3/MP4 menus expose only bundled media, without browsing, SMS or carrier billing. The generated MP4 is an original 12-second pixel animation; rebuild with `python3 scripts/build-pocket-video.py`.

`dist/images/daming/00.jpg` through `32.jpg` are web derivatives of the author's already published first volume r08, integrated at the author's explicit request. Source: the published snapshot `2026-10-14/token/发布快照/vol01-r08/成稿` (cover and P01–P32). Pending review candidates are excluded. Comic artwork retains its existing author's rights and is not relicensed by the code license.

24 SMS advert offers are interactive fiction. All prices and refunds use local virtual credit. One-time downloads refund their recorded purchase amount at most once while owned; monthly subscriptions can be cancelled individually or together with the discovered TD command. Downloads already saved outside the game are not erased. No real carrier, phone, account, payment, or public messaging API is called.

The support panel provides local applause only. Real voluntary donations remain unavailable until the author supplies their public payment destination.

UC website selection queries Internet Archive's availability API and only embeds a snapshot within the selected year and on/before the target date. Timeouts, missing snapshots and network restrictions are displayed honestly with an archive-site link; recreated WAP content stays under an explicitly labelled collapsed section.
