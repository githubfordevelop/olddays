# v0.2.0 阅读页审核记录

## 本次改变

- 重新编排 1996—2025 年每年 10 个选题，去除截断标题与同年同事件重复项。
- 300 篇正文以明确署名的维基百科节选组成，短条目补充相关主题背景；10 个原有机构来源摘要保留在当年事件部分。
- 资料固定到修订版本，正文、背景分别标明出处；内容许可与 MIT 代码许可分开。
- 老门户双栏、移动 WAP 版式、目录、字号、上下篇和共建入口。

## 已验证

- 8 项应用行为测试与 4 项发布器测试通过。
- 全部 300 条新闻可以在站内打开；正文最短 781 字符、平均约 1635 字符；检查正文长度、引用版本、许可与参与入口。
- 新增正文和标题 HTML 注入测试通过；不使用来源 HTML 执行脚本。
- 390px 手机视口没有横向溢出；正文从 16px 切换到 20px 生效。
- 桌面采用双栏，手机自动变为单栏，相关内容排到正文之后。

## 编辑边界

本次检查覆盖来源关联、文本长度、条目缺失/消歧、代表性页面与渲染行为，并不代表每个百科事实已独立交叉核实。历史资料可能包含后续发展；界面明确标注，不将它们包装为当年即时报道。欢迎通过勘误与 PR 继续逐篇核实、补充更直接的机构出处。正文分节基于来源节选，未臆造记者、媒体署名、评论数量或现场采访。
