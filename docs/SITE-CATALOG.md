# 旧站目录编辑说明

目录数据：`dist/site-catalog.js`。目前 14 类、240 个独立旧域名或子域名入口。按网站入口计数，不代表 240 个互不相关的品牌。

`since` 是编辑建议开始浏览的年份，用于减少早期年代出现较晚网站的情况，不是精确上线日期或域名启用日期。目录收录是候选线索，不代表已验证该站在每一年有可读快照。实际打开仍调用 Wayback 查询并核验所选年份与日期，保留浏览器外壳。不要把目录数量写成“240 个已恢复网站”。

首批重点域名资料：
- 一搜（雅虎，yisou.com）：[2004 年上线报道](https://tech.sina.com.cn/i/w/2004-06-22/0845378532.shtml)。与宜搜 easou.com 分列，搜索词中保留用户常写的“易搜”。
- 天涯早期 tianyaclub.com 与 2005 年 11 月 tianya.cn：[当时域名变更报道](https://tech.sina.com.cn/i/2005-11-11/0947763324.shtml)。常用入口在 2005-11-01 之前自动选择早期域名。
- 梦网 WAP 地址：[手机上网业务说明中的 wap.monternet.com](https://www.c114.com.cn/wireless/2945/a625216.html)。

其余条目是编辑整理的旧址线索，尚未逐条做实时快照覆盖审计。登录、发帖、支付、下载、Flash、WML 页面和服务器游戏通常不能重现。手机站存档也可能以原始格式下载或无法内嵌，本站没有仿造这些远端服务。

新增条目请提交站名、当年网址、建议年代及可核实来源；同一品牌换域名可分别收录，不要把今天重注册的域名内容当作旧站。所有目录链接只用于历史存档查询，不直连当前域名。
