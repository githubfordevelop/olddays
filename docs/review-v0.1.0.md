# v0.1.0 本次代码审核记录

审核日期：2026-10-19。范围：静态页面、用户输入与本机存储、年度新闻数据结构、小游戏、GitHub 工作流、静态发布与回滚逻辑。

## 已修复

- 日期输入与收藏日期检查接受了不存在或自动滚动的日期；现拒绝无效日期，避免页面异常或时间坐标失真。
- 皮肤与内部地址查找可能误用对象继承的属性；现仅接受明确的自有键。
- 收藏加载缺少格式、协议和时间范围检查；现过滤损坏数据和不支持的网址协议。
- 从新闻详情切换日期后可能继续显示旧年份内容；现返回新年份的年度首页。
- 年份切换遇到闰年2月29日时，现将目标日期限制到对应月份的合法日期。

## 验证

- JS 语法、网页静态资源引用、移动端 manifest 通过。
- 1996—2025 共30年，每年10条，合计300条；重复标题与空字段检查通过。
- 6项应用行为测试通过：非法日期、损坏收藏与皮肤、种菜完整循环、练功升级与胜利、新闻详情及年份切换、全部300条资料卡渲染。
- 4项发布行为测试通过：拒绝其他仓库的CI、拒绝ZIP路径穿越、仅发布dist并记录提交、HTTP健康检查失败时恢复旧版本。
- 浏览器390px视口验证了新闻数量、站内导读、来源链接与无横向溢出，并保存实际截图。
- 发布脚本不读取或上传私钥到源码；服务器采用受限普通用户，只拉取通过main分支CI的公开静态文件，不执行下载仓库的脚本。

## 内容与运行边界

年度事件是事实索引与编辑导读，不是原始新闻全文。部分核心事件提供扩展导读，其他条目为简要资料卡；百科索引记录了来源修订号，仍应继续编辑校对，数量检查不能替代史料核验。

外部网页存档可能缺失或跨日期；游戏是原创本机互动。GitHub工作流和服务器的实际运行情况以Actions、服务日志及公开version.json为准。首次站点迁移需保留旧配置并单独核验HTTP入口。
